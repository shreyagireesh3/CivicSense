# Project Coding Rules (Non-Obvious Only)

- All React components live in the **single file** `dashboard/src/App.jsx`. Do not create new component files — this is intentional.
- The dashboard has no TypeScript; no `tsconfig.json` exists. Keep files as `.jsx`, never `.tsx`.
- Tailwind v4 is configured via the Vite plugin only — there is **no** `tailwind.config.js`. Never create one; it breaks the build.
- Adding a new analytics API endpoint requires a JSON file in `dashboard/public/data/` (generated by notebooks). The analytics backend never writes files.
- `dashboard/` has its own `node_modules` — all `npm` commands must run from `dashboard/`, not project root.
- **Two venvs**: Use `.venv-1` for backend/tests (has FastAPI, httpx, pytest). `.venv` does NOT have FastAPI.
- Notebook scripts use `Path(__file__).resolve().parent.parent` to derive project root — follow this if adding new scripts.
- `oxlint` (not ESLint) is the linter. Run from `dashboard/`: `npm run lint`. No `eslint.config.js` exists.
- The `react/set-state-in-effect` rule is explicitly disabled in `.oxlintrc.json` — do not add workarounds for it.
- **API field split**: top-level endpoints (`/categories`, `/wards`, `/monthly`, `/status`) use field `complaints`. Drill-down endpoints use `count`. Both arrive as strings — always coerce with `Number()`.
- Null display pattern: `value != null ? formatNumber(value) : "—"` — never hardcode numeric fallbacks.
- Failed fetch returns `{ _error: true }` sentinel; required-key failures set `apiError` → renders `ApiErrorScreen`.
- Color palette is defined in `PASTELS`, `INSIGHT_ACCENT_COLORS`, `INSIGHT_CARD_BG`, `STATUS_PIE_COLORS`, `CATEGORY_BAR_COLORS` at the top of `App.jsx` — use these constants, never inline hex colors for chart elements.
- Backend tests use `httpx` via `starlette.testclient.TestClient`. Import path requires `conftest.py` at project root adding root to `sys.path`.
- **Service Desk** (`backend/desk.py`): SQLite at `data/desk.db` (auto-created). Valid statuses: `{"Received", "Under Review", "Action Taken", "Resolved", "Reopened"}`. `PATCH /api/desk/tickets/{id}` enforces this set and rejects others with 422.
- Desk tests **must** monkeypatch `desk.DB_PATH` to a `tmp_path` file to stay isolated — see `backend/tests/test_desk.py` fixture pattern.
